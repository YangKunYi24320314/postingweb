# D3 辅助开发提示词记录

1. 对照项目 Apifox 接口契约开发帖子详情页，基于 Vue3 + Element Plus 实现帖子核心信息完整渲染，严格对齐接口返回字段规范，同时完成页面路由注册与帖子列表页的跳转联动。

2. 帖子详情页需与登录系统实现深度联动，如何复用项目现有 auth 认证模块获取当前登录用户身份，建立页面级权限上下文，实现登录态与页面功能入口的联动控制。

3. 实现多类型附件上传功能，支持图片、文档、视频三类主流文件，前端如何实现文件格式校验与 100MB 大小前置拦截，给出完整的文件选取、状态反馈与文件流提交的前端交互方案。

4. 后端 Express 服务如何接收多类型上传文件，配置静态资源托管目录，实现文件存储、访问路径返回与下载链路打通，同时补充服务端的文件类型与体积二次校验。

5. 多类型文件上传过程中频繁出现失败问题，如何沿上传全链路逐节点排查故障点，设计独立的附件数据表统一存储文件元数据，规范存储路径与关联关系，提升上传功能稳定性。

6. 实现帖子删除的权限控制机制，要求仅帖子本人与管理员可执行删除操作，如何基于当前登录用户 ID 与角色字段实现前后端双重权限校验，拦截越权操作。

7. 复用项目 auth.js 中的 getMe 接口获取用户身份信息，用于帖子删除的权限校验，给出完整的身份拉取、权限匹配判断与操作入口显隐控制的实现逻辑。

8. 优化分类与标签系统，梳理分类筛选的参数传递逻辑，统一标签在列表、详情等多场景下的渲染与解析格式，解决字段格式不一致导致的筛选与展示异常问题。

9. 新增附件信息数据表存储多媒体 / 文档元数据，如何设计合理的表结构与帖子关联关系，同时保障团队成员数据库结构自动同步，无需每人手动执行 SQL。

10. 功能开发完成后如何开展代码自查，校验接口字段与协议一致性、权限逻辑完整性与边界场景处理，按团队 Git 规范提交功能分支，保障代码质量符合协作开发标准。
