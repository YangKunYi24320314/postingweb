# D4 辅助开发提示词记录

1. 多格式附件在线预览方案选型与实现，明确浏览器原生预览的格式边界（图片 / PDF / 视频），针对 Office 文档设计双方案适配：公网部署可接入微软在线预览服务，本地开发环境可采用纯前端 docx-preview 渲染库；当前版本采用降级策略，不支持原生预览的格式自动触发下载，兼顾兼容性与功能可用性。
2. 统一封装多类型附件预览触发逻辑，集中处理文件路径归一化、MIME 类型识别、预览模式分发，修复路径双斜杠导致的域名解析失败问题，规范不同格式的弹窗交互与加载流程，保证预览体验一致性。
3. 帖子软删除机制设计与落地，将物理删除改造为时间戳标记删除模式，数据库新增删除标识字段；同步改造全量帖子查询接口，默认过滤已删除数据，在前端用户无感知的前提下保留数据可恢复性与操作审计能力。
4. 帖子列表与详情页的分页记忆联动实现，通过 URL query 参数传递分页状态，详情页返回时携带原页码参数，列表页读取参数自动定位到对应分页，避免用户跳转后重复翻页，提升浏览路径连贯性。
5. 前端 history 路由模式的后端适配方案，解决 Express 静态托管下子页面刷新 404 问题；采用中间件兜底策略，精准区分接口请求、静态资源与前端路由，非接口非静态的 GET 请求统一返回 index.html 交由 Vue 路由接管。
6. 局域网多设备互通部署全流程配置，后端监听地址改为 0.0.0.0 放开局域网访问权限，通过 BASE_URL 环境变量统一生成附件访问地址，前端打包后由后端单端口托管，配合 Windows 防火墙入站规则配置，实现同 WiFi 环境下全功能互通。
7. 局域网部署连通性问题排查方法论，沿「网络层 - 端口层 - 应用层 - 资源层」逐层定位：先 ping 验证网络连通性，再测端口与防火墙策略，最后校验接口路径与静态资源地址，系统性解决外部设备访问失败、附件下载地址错误等问题。
8. 校园网环境下的 Git 协作问题处理，针对 GitHub 域名解析失败明确网络限制根因，采用切换手机热点的快速解决方案；规范功能分支提交流程，确保代码版本可追溯与团队协作同步。
9. 前端打包与后端托管的路径适配方法，明确 dist 目录相对路径配置规则，可通过打印绝对路径调试定位路径不匹配问题，覆盖 Vue 项目打包后静态资源路径、路由匹配的常见坑点。
10. 功能迭代后的代码自查标准，覆盖接口字段一致性、权限逻辑完整性、边界场景异常处理三个维度，按团队规范提交至对应功能分支，保障代码质量符合协作开发标准。
