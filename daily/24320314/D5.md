## 遇到的问题与解决

1. **`about.html` 是独立静态页，取不到设计变量**：Vite 不构建 `public/` 下的页面，无法引用 `src/styles/tokens.css`，也不可用 Element Plus。**解决**：在该页 `:root` 内联复刻 `tokens.css` 的设计变量，并注释说明"唯一设计变量来源"，保证风格统一、不写死色值。
2. **独立静态页无法走 `vue-router` 路由跳转**：放在 `views/` 里会被路由接管，不是静态资源。**解决**：放在 `public/` 作为静态页，首页按钮用整页跳转 `window.location.href = '/about.html'`，入口/返回都正常。
3. **过期与冗余文档容易误导**：`sample_posts_seed.sql`、`docs/superpowers`、旧 `plans`/`specs` 与当前实现不符。**解决**：统一删除，避免队员按旧文档写代码；安全中心内容合并进 `SecurityCenterView`。
4. **回收站详情重复维护**：为"已删除帖"另做详情页会与通用详情页重复。**解决**：后端仅在详情接口透传管理员角色（跳过软删除过滤 + 返回 `is_deleted`），前端复用通用详情页，只在特定组合场景显示管理按钮，交互体验统一。
5. **合并冲突/规范不统一**：队友分支写法、字段、返回格式仍有差异。**解决**：用 AGENT 逐文件对照 `api-protocol.md` 核点，把不合规处集中反馈。
