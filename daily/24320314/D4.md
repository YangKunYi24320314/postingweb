## 遇到的问题与解决

1. **旧 `/upload` 写死 `127.0.0.1`**：局域网或部署后，别人访问图片/头像会 404。**解决**：改用 `req.get('host')` 相对拼地址，随访问者 host 动态变化。
2. **端口与调试日志**：`PORT` 写死、日志直接打印数据库密码。**解决**：`PORT` 统一从 `.env` 读（默认 3000），删掉打印密码的调试日志。
3. **单端口访问不到网站**：`client` 未 `npm run build` 时后端拿不到页面。**解决**：`server.js` 检测 `client/dist` 存在才托管，否则提示先去 build，并把该场景写进 FAQ。
4. **推荐与契约不符**：契约里还留着独立 `/recommend/posts`，实际推荐已并入 `?rank=recommend`。**解决**：删掉 `openapi.yaml` 里该接口，统一按 `rank` 走，并同步 `AGENTS.md` / `README.md`。
5. 队员代码写法、字段、返回格式不统一，审查工作量大。**解决**：用 AGENT 逐文件对照 `api-protocol.md` 核点，把不合规处集中反馈，并再次提醒"只加路由文件、别动公共入口、走统一封装、只用 tokens.css 变量"。
