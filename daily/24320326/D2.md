## 遇到的问题与解决

1. **后端依赖不完整**（缺 `bcryptjs`/`jsonwebtoken`/`prettier`）→ 在 `server/` 目录 `npm install` 补齐。
2. **`.env` 未建导致连库 500** → 复制 `.env.example` 为 `.env` 并填 `DB_PASSWORD`。
3. **PostgreSQL 主键为 BIGINT，node-postgres 返回字符串**（如 `id` 是 `"1"` 而非 `1`）→ SQL 查询里对这类字段加 `::int` 转数字。
4. **合并 develop 时的 4 处冲突** → 分析后 `git checkout --theirs` 采用 develop 版（auto-load、封装、代理、锁文件），并手动适配 auth 导入。
5. **前端 lint 警告**（`vue/attributes-order` 属性顺序，如 `v-loading` 应在 `:data` 前）→ `npm run lint:fix` 自动修复。
6. **旧 token 与合并后后端** → 因 `JWT_SECRET` 未变，旧 token 仍有效，联调未受影响。
