## 遇到的问题与解决

1. **问题**：前端打包后由后端托管时，出现根路径及子页面 404 报错，页面无法正常访问。**解决**：定位为 Vue history 路由模式与后端静态托管的匹配问题，纯静态文件托管无法处理前端路由路径。新增全局中间件兜底逻辑，精准拦截非接口、非静态资源的 GET 请求，统一返回 index.html 交由 Vue 路由接管，同时保证接口与静态资源正常响应，彻底解决 history 模式下的页面 404 问题。
2. **问题**：docx 等 Office 格式文档无法实现浏览器原生预览，直接打开会触发下载，用户体验不连贯。**解决**：梳理浏览器原生支持的预览格式边界，明确仅图片、PDF、视频可原生渲染；针对 Office 格式设计双方案适配，本地开发环境可采用纯前端渲染库实现本地预览，公网部署场景可接入微软在线预览服务；当前版本采用降级策略，识别到不支持预览的格式自动触发下载，保证功能可用不报错。
3. **问题**：局域网部署阶段出现外部设备无法访问、端口不通、附件下载地址错误等一系列连通性问题。**解决**：沿网络链路逐层排查，依次解决三个核心问题：后端监听地址改为 0.0.0.0 放开局域网访问权限；配置 Windows 防火墙入站规则放行 3000 端口；修正附件返回地址为局域网 IP，避免客户端指向本地路径。最终完成多设备互通验证，全功能正常运行。
4. **问题**：代码提交 GitHub 时出现域名解析失败，无法推送远程仓库。**解决**：定位为校园网 DNS 解析限制导致 GitHub 无法访问，切换手机热点网络后成功完成推送，保障代码版本同步与可追溯。
