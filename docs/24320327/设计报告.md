# 帖子模块开发进展汇报

本次汇报覆盖四天内帖子模块的全链路开发工作，涵盖基础发帖、详情交互、附件体系、管理员回收站四大核心板块，已完成用户发布、浏览、附件交互到管理员内容管理的完整业务闭环，全部代码已提交至 `develop-post` 分支。

## 一、基础发帖功能建设

完成发帖页面开发与前后端联调。前端基于 Vue3 + Element Plus 实现 `WritePostView.vue` 页面，严格遵循 Apifox 接口契约设计表单，仅保留标题、正文、分类、标签四个规范字段，实现必填项校验与标签格式转换逻辑。后端基于 Express 搭建对应接口，打通 PostgreSQL 数据库写入链路；同时独立封装 post 模块请求文件，完成路由注册与导航入口适配，构建完整的发帖业务链路。

**遇到的问题与解决：**

1. 接口鉴权调试问题：发帖接口受 JWT 身份鉴权保护，在完整用户认证体系未落地的阶段，采用模拟用户凭证的方式构造合法登录上下文，保障了受限接口的本地开发与调试。
2. 前后端通信连通问题：针对服务跨域、请求地址、报文格式等多维度对接障碍，从服务配置、跨域策略、请求代理逐层排查定位，完成前后端服务对接配置，建立稳定的数据交互通道。
3. 接口字段对齐问题：针对前端请求体与接口规范的参数偏差，以团队统一的接口协议文档为标准，重构前端请求逻辑，严格对齐请求方式、路径与传参结构，消除接口适配偏差。

## 二、帖子详情与附件上传体系

完成帖子详情页、多类型附件上传与删除权限控制功能。详情页完整渲染帖子标题、正文、作者信息、发布时间、标签、互动统计等核心字段，对接项目 auth 认证模块，实现登录态与页面操作入口的联动控制。附件上传支持图片、文档、视频三类主流格式，前端实现文件格式识别与 100MB 大小前置校验；后端设计独立的 `post_attachments` 表存储文件元数据，替代帖子表内嵌存储方案，降低数据冗余，打通上传、存储、下载全链路。删除权限采用前后端双重校验机制：前端基于用户 ID 与角色字段控制操作按钮可见性，后端接口二次校验身份权限，拦截越权操作。

**遇到的问题与解决：**
针对多类型文件上传失败频发的问题，沿上传全链路逐节点排查，定位根因为前端大小校验缺失、后端接收配置限制与存储路径不规范。通过补充前端格式与大小前置校验、调整后端文件上传限制与超时配置、设计独立附件表统一管理文件元数据与存储路径，系统性提升了上传功能的稳定性。

## 三、附件预览与软删除机制落地

完成附件在线预览功能、帖子软删除机制改造与局域网部署适配。附件预览覆盖三类主流格式：图片采用弹窗大图预览、PDF 采用 iframe 内嵌渲染、视频采用原生控件播放；针对 docx 等浏览器不支持原生预览的 Office 格式，设计降级策略，自动触发下载，兼顾格式覆盖度与功能可用性。落地软删除机制，在数据库新增 `is_deleted` 标记字段，所有查询接口默认过滤已删除数据，在前端无感知的前提下保留数据可恢复性与操作审计能力。完成局域网部署适配：后端修改监听地址为 0.0.0.0 放开局域网访问权限，新增全局中间件实现 SPA history 路由兜底，配合 Windows 防火墙入站规则配置，实现同 WiFi 环境下多设备全功能互通。

**遇到的问题与解决：**
针对前端打包后静态托管子页面刷新 404 的问题，定位为 Vue history 路由模式与 Express 静态托管的适配问题。通过新增全局中间件兜底策略，精准区分接口请求、静态资源与前端路由，将非接口、非静态资源的 GET 请求统一返回 index.html 交由 Vue 路由接管，彻底解决子页面刷新 404 问题。

## 四、管理员回收站功能实现

完成管理员帖子回收站全链路功能。后端新增已删除帖子分页列表、单帖详情、帖子还原三个管理接口，权限控制下沉至数据查询层，默认对普通用户屏蔽已删除内容，管理员角色可穿透访问。前端采用组件复用方案，基于通用帖子详情页新增「已删除」状态标签与「还原帖子」操作按钮，通过「用户角色 + 帖子删除状态」双维度计算属性控制交互元素显隐，一套视图同时承载普通用户浏览与管理员管理双场景，避免重复开发，有效降低代码冗余。最后完成冗余路由与废弃文件清理，保障代码库整洁。

**遇到的问题与解决：**

1. 开发环境路径缓存问题：新建 admin 接口文件后 Vite 开发服务器出现路径解析失败，定位为开发服务器模块缓存机制导致。采用同级相对路径导入方案快速绕过缓存问题，同时验证清除 `.vite` 缓存后重启服务可彻底恢复别名路径解析。
2. 数据表名不匹配问题：管理员详情接口查询附件时报错，通过 SQL 报错定位表名偏差，确认附件表实际名称为 `post_attachments`，修正表名并对齐字段返回格式，保障前端附件组件可直接复用。
