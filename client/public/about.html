CAMPUS HUB

校园社区

定制化打造的发帖社区论坛。在这里分享校园生活、发布帖子、参与讨论，找到同频的交流与灵感。

项目名称 CampusHub；仓库开发代号 PostWEB（见下方 GitHub 仓库）。

我们想做什么

目前校园发帖互动依托校园墙，QQ，微信等等，不统一且管理不便，我校百度贴吧热度不高，使用人数少且无法客制化。CampusHub 想把它们汇聚到一个可浏览、可互动、可追溯的网页里，让校园分享更有秩序。

  • 轻松浏览与发现：分类、标签、关键词搜索，以及按最新 / 热门 / 推荐多种方式排序。
  • 自由表达：发布帖子、上传附件，实现主流发帖功能。
  • 热闹的互动：评论、楼中楼回复、点赞与收藏，让讨论更有温度。
  • 专属记录中心：各类历史记录、我的内容，以及头像与背景图等个人设置。

核心功能模块

用户与认证

实现注册、登录、个人信息管理，用户和管理员权限区分。

帖子核心

发布、删除、筛选、搜索，支持附件上传与下载，列表筛选排序。

互动系统

评论与楼中楼回复、点赞、收藏，让交流更丰富。

记录中心

历史记录、我的内容、头像，背景图与安全设置，信息统计。

技术栈

Vue 3 + Vite 前端 · Element Plus
Node.js + Express 后端 API
PostgreSQL 数据库

关于本项目

本项目由 5 名成员协作开发，采用全员按功能和模块全栈开发的模式，旨在用一套清晰的契约（接口协议、数据库设计、统一设计变量）把多人协作的复杂度降到最低。
